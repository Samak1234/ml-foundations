# used-car-price-prediction

Beginner machine learning project for predicting used-car selling prices.

## What I’ve done
- Cleaned and prepared the dataset
- One-hot encoded categorical features
- Trained a Linear Regression model
- Evaluated with MAE, RMSE, and R²
- Analyzed prediction errors and residuals
- Added `Car_Age` feature engineering
- Started comparing with a Decision Tree Regressor

## Tech
Python, Pandas, Scikit-learn, Matplotlib
